# ARMORA — каталог входных дверей

Статичный каталог + конфигуратор для **каталог.армора.рф**

## Деплой
Любой статический хостинг — все файлы статические:
- `index.html` — единственный HTML
- `img/doors/*.webp` — фото 54 моделей (~6 МБ)
- `bg.png` — фон hero
- `doors-armora.json` — данные (опционально, всё уже встроено в index.html)

## Локально
Открыть `index.html` в браузере. Сборки нет.

## Лиды
Заявки уходят через `sendLeadToBackend()` в `index.html`.
По умолчанию — `console.log`. Подключить Telegram-бот / Formspree / webhook
правкой константы `LEAD_ENDPOINT` в `<script>` блоке.
